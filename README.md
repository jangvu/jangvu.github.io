# Hoang Giang Vu — Academic Portfolio

Static portfolio website prepared for GitHub Pages.

## Publish with GitHub Pages

1. Create a new GitHub repository.
2. Upload every file and folder from this package, keeping `index.html` at the repository root.
3. Open **Settings → Pages** in the repository.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and the `/ (root)` folder, then save.

The website uses plain HTML, CSS, and JavaScript. No build command or package installation is required.

## Structure

```text
index.html
publications.html
assets/
  style.css
  site.js
  CV_HoangGiangVU.pdf
```

Update the short profile in `index.html`, publication records in `publications.html`, visual styling in `assets/style.css`, and mobile-menu behavior in `assets/site.js`.
